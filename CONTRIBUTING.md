# Contributing to Telmmon D3

Thank you for your interest in contributing to Telmmon D3.

## Getting Started

1. Fork the repository.
2. Clone your fork.
3. Install the required dependencies.
4. Create a branch for your changes.
5. Make and test your changes.
6. Open a pull request.

## Issues

Bug reports and feature requests are welcome.

Please provide enough information for an issue to be reproduced or understood.

## Pull Requests

Please keep pull requests focused on a specific change.

For larger changes, open an issue first so the architecture can be discussed before implementation.
